# 0001 · Record architecture decisions

- Status: Accepted
- Date: 2026-11-12

## Context
Decisions get lost in commit messages and chat history.

## Decision
Every decision that shapes the code gets a short ADR in `docs/adr/`, in the same PR as the code it affects.

## Consequences
The reasoning stays next to the code. A changed decision gets a new ADR that supersedes the old one.
